# Parking Management System

A web-based Parking Management System developed as a Data Structures coursework project.

## Features

- Vehicle registration
- Parking slot allocation
- Parking availability checking
- Waiting queue when the parking area is full
- Vehicle entry and exit management
- Parking fee calculation
- Database storage
- Web-based user interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Data Structures and Algorithms

## Data Structures

The system makes use of data structures such as:

- Arrays/Lists
- Queues
- Stacks
- Other structures required by the system
